## 📌 Project Overview
In modern technical recruitment, successful candidate submission and account development depend on identifying the **exact hiring managers who own requisition headcount and budget**, rather than submitting blind applications to generic HR portals.

This project delivers:
1. **Requisition Deconstruction:** Thorough analysis of 5 live US engineering openings across Chicago, Woodridge, and Roselle, IL.
2. **Executive & Management Hierarchy Mapping:** High-to-low mapping (C-Suite → SVP/VP → Head/GM → Director → Engineering Manager).
3. **Multi-Source Sourcing & Verification:** Cross-referencing LinkedIn Talent directories with official corporate disclosures, SEC filings, and engineering trade publications.
4. **Master Deliverable Workbook:** An 8-sheet Excel workbook (`Gagan_Dhanapune_DataAnalyst.xlsx`) structured for recruiter outreach pipelines.

## 🛠️ Recruitment Techniques & Tools Applied
* **Boolean Query Design:** Tailored logical search operators across corporate directories.
* **Organizational Chart Reverse-Engineering:** Mapping reporting lines to pinpoint the exact manager overseeing the requisition.
* **Talent Verification Auditing:** Verification across press releases, SEC 8-K filings, and trade media (catching executive turnovers like departures and interim CTO appointments).
* **Advanced Excel (`openpyxl`):** Custom color coding, cell styling, embedded hyperlinks, and consolidated database schema.
